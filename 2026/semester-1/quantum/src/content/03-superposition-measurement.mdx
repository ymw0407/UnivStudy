2장의 half adder는 고전 입력만 받아서 고전 덧셈기와 다를 게 없었다. 이번 장에서 입력을
**중첩** 으로 바꾸면, 같은 회로가 네 개의 덧셈을 한 번에 처리한다. 그리고 그 결과를
**측정** 하는 순간 무슨 일이 벌어지는지 본다.

## 게이트 5: H 게이트 — 중첩을 만든다

**Hadamard 게이트(아다마르 게이트, H)** 는 큐비트를 0/1의 **반반 중첩** 으로 보낸다.

| 입력 | 출력 |
|------|------|
| `\|0⟩` | `\|+⟩ = (\|0⟩ + \|1⟩) / √2` |
| `\|1⟩` | `\|−⟩ = (\|0⟩ − \|1⟩) / √2` |

`|0⟩`에 H를 걸면 `|+⟩` 상태가 된다. 측정하면 0과 1이 각각 50%로 나오는 상태다. `1/√2`
라는 숫자가 왜 붙는지는 곧 설명한다.

<Callout kind="note">
`√2`로 나누는 이유: 측정 확률은 각 항 계수의 **제곱** 이다. `|0⟩`과 `|1⟩`이 각각 50%가
되려면 계수가 `1/√2` 여야 한다. `(1/√2)² = 1/2 = 50%`. 두 확률의 합은 `1/2 + 1/2 = 1`.
</Callout>

## 입력을 중첩으로: 한 번에 네 개의 덧셈

half adder의 입력 `A`(q[0])와 `B`(q[1])에 X 대신 **H** 를 건다. 단계별로 상태를 따라가자.

**시작:** `|ψ₀⟩ = |0000⟩`

**H 두 개를 건 뒤** — `A`와 `B`가 각각 `|+⟩` 가 되어, 둘의 모든 조합이 동시에 존재한다.

$$
|\psi_1\rangle = \tfrac{1}{2}\,\bigl(|0000\rangle + |0001\rangle + |0010\rangle + |0011\rangle\bigr)
$$

`q₁q₀` 부분이 `00, 01, 10, 11` — 즉 `(A,B)`의 네 가지 입력이 **한 상태 안에** 다 들어
있다.

<Figure
  src="/figures/ch03-h-gate.png"
  caption="q[0]·q[1]에 H 게이트를 건 |00++⟩ 상태. Statevector·Probabilities 패널에 0000·0001·0010·0011 네 막대가 똑같은 높이로 서 있다 — A·B의 네 조합이 동시에 존재한다는 뜻."
  source="「프로그래밍으로 배우는 양자컴퓨팅」 강의자료"
/>

**half adder(CX·CX·CCX)를 통과시킨 뒤** — 회로는 네 항 **각각에** 덧셈을 적용한다.

$$
|\psi_2\rangle = \tfrac{1}{2}\,\bigl(|0000\rangle + |0101\rangle + |0110\rangle + |1011\rangle\bigr)
$$

각 항을 `|q₃q₂q₁q₀⟩ = |CARRY, SUM, B, A⟩` 로 읽어 보자.

- `|0000⟩` : 0+0 → sum 0, carry 0 ✓
- `|0101⟩` : 1+0 → sum 1, carry 0 ✓
- `|0110⟩` : 0+1 → sum 1, carry 0 ✓
- `|1011⟩` : 1+1 → sum 0, carry 1 ✓

**게이트를 한 세트만 걸었는데 네 개의 덧셈이 전부 끝나 있다.**

## 왜 이게 가능한가: 양자 연산은 선형이다

비결은 양자 연산(게이트)이 **선형(linear)** 이라는 데 있다. 선형이라는 건 이런 성질이다.

$$
f(\alpha\,x + \beta\,y) = \alpha\,f(x) + \beta\,f(y)
$$

> 입력이 여러 상태의 **합(중첩)** 이면, 출력도 "각 상태에 따로 연산한 결과들의 합" 이다.

half adder 회로를 `f`라고 하면, 입력 `|ψ₁⟩`은 네 상태의 합이다. 선형성 덕분에 `f`는
네 항 각각에 덧셈을 적용하고 그 결과를 다시 합쳐 준다. 이것이 양자컴퓨팅에서 말하는
**양자 병렬성** 의 출발점이다.

<Callout kind="warn">
모든 함수가 선형인 것은 아니다. 예를 들어 `f(x) = x²` 는 `f(1+2) = 9 ≠ f(1) + f(2) = 5`.
양자 게이트는 **반드시** 선형이어야 한다 — 이 제약이 2부 9장에서 "양자 연산 = 행렬"로
이어진다.
</Callout>

## 슈뢰딩거의 고양이

`|ψ₂⟩` 처럼 여러 결과를 동시에 품은 상태를, 유명한 비유로 **슈뢰딩거의 고양이** 라
부른다.

> 상자 안에 고양이와, 확률적으로 작동하는 독약 장치가 있다. 상자를 **열어 보기 전** 까지
> 고양이는 "살아 있음"과 "죽어 있음"의 **중첩 상태** 다.

우리 회로에서 `|ψ₂⟩`는 네 개의 덧셈 결과가 겹쳐 있는, 정확히 그 "상자를 열기 전"
상태다.

### 확률진폭과 측정 확률

각 항 앞에 붙은 계수(`|ψ₂⟩`에서는 모두 `½`)를 **확률진폭(probability amplitude)** 이라
한다. 어떤 항이 측정될 **확률은 그 진폭의 절댓값의 제곱** 이다.

$$
\left|\tfrac{1}{2}\right|^2 + \left|\tfrac{1}{2}\right|^2 + \left|\tfrac{1}{2}\right|^2 + \left|\tfrac{1}{2}\right|^2 = \tfrac{1}{4} + \tfrac{1}{4} + \tfrac{1}{4} + \tfrac{1}{4} = 1
$$

네 결과가 각각 25% 확률로 나오고, 모든 확률을 더하면 1이 된다. (진폭의 제곱이 확률이라는
점은 4장의 복소수, 6장의 "확률진폭"에서 더 정확하게 다룬다.)

<Callout kind="warn">
**측정의 한계**: 회로는 네 덧셈을 동시에 했지만, 측정은 그중 **하나** 만 돌려준다. 그래서
양자 알고리즘 설계의 핵심은 "원하는 답의 진폭만 크게 만들어서, 측정했을 때 그게 잘 나오게"
하는 것이다. 그냥 병렬로 계산한다고 공짜로 답이 다 나오는 게 아니다.
</Callout>

### 측정은 어떤 "기저"로 하는가

위에서 한 측정은 `|0⟩`/`|1⟩` 중 하나로 결과가 나오는 측정 — 이를 **계산 기저
(computational basis, Z 기저)** 측정이라 한다. 측정에는 다른 기준(기저)도 있다는 점만 지금
기억해 두자. "기저"가 정확히 무엇인지는 2부 7장의 주제다.

### 회로를 함수로 — 모듈화

회로가 커지면 같은 패턴을 여러 번 쓰게 된다. 위 half adder 부분을 **함수로 빼서 재사용**
할 수 있다.

```python
from qiskit import QuantumRegister, QuantumCircuit

def half_adder(n):
    qr = QuantumRegister(n)
    qc = QuantumCircuit(qr)
    qc.cx(qr[0], qr[2])
    qc.cx(qr[1], qr[2])
    qc.ccx(qr[0], qr[1], qr[3])
    qc.name = 'half_adder'
    return qc
```

이 함수를 호출하면 회로 객체가 돌아오고, 메인 회로에 **블록 하나로** 붙일 수 있다.

```python
qreg_q = QuantumRegister(4, 'q')
creg_c = ClassicalRegister(4, 'c')
circuit = QuantumCircuit(qreg_q, creg_c)

circuit.x([qreg_q[0], qreg_q[1]])    # A=1, B=1 — 리스트로 한 줄에
circuit.barrier()

# 두 가지 방법:
circuit.append(half_adder(4), [0, 1, 2, 3])           # 블록으로 (회로도에 사각형으로 표시)
# circuit.compose(half_adder(4), range(4), inplace=True)  # 게이트로 펼침 (블록 사라짐)

circuit.measure(qreg_q, creg_c)
```

<Figure
  src="/figures/ch03-qiskit-half-adder-fn.png"
  caption="half_adder() 를 함수로 정의한 뒤 append() 로 메인 회로에 끼우면 보라색 블록으로 표시된다. compose() 를 쓰면 안쪽 CX·CCX 가 그대로 펼쳐진 모습이 보인다."
  source="「프로그래밍으로 배우는 양자컴퓨팅」 강의자료"

`append` 와 `compose` 의 차이:
- `append(...)` → 그림에 **하나의 블록** 으로 표시. 안 풀어서 보기 깔끔.
- `compose(..., inplace=True)` → 안쪽 게이트들을 **펼쳐서** 메인 회로에 합침.

### 시뮬레이터로 실제로 돌리기 — AerSimulator + SamplerV2

qiskit 코드만 적고 실행 안 하면 회로 그림만 보고 끝난다. 실제로 측정 결과 분포를 얻으려면
**시뮬레이터** 에 보내야 한다. 신버전 qiskit 의 표준 워크플로우는 다음과 같다.

```python
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import SamplerV2 as Sampler
from qiskit_aer import AerSimulator

aer_sim = AerSimulator()                                 # 시뮬레이터 백엔드
pm = generate_preset_pass_manager(backend=aer_sim, optimization_level=1)
isa_circuit = pm.run(circuit)                            # 회로를 백엔드에 맞게 변환

sampler = Sampler(mode=aer_sim)
job = sampler.run([isa_circuit], shots=1000)             # 1000번 측정
result = job.result()
count = result[0].data.c.get_counts()                    # 'c' 는 classical register 이름
print(count)

```

입력에 H 게이트로 중첩을 주면 위 코드 그대로 돌려도 측정 분포가 4가지 (또는 더 많은) 값에
퍼진다 — 1부의 "한 번에 네 덧셈" 이 실제 숫자로 보이는 순간이다.

<Callout kind="summary">
- **H 게이트**: `|0⟩` → 0/1 반반 중첩(`|+⟩`)
- 입력을 중첩으로 넣으면 한 회로가 **모든 입력의 계산을 동시에** 수행 — 양자 연산이
  **선형** 이기 때문
- **측정**: 중첩이 무너져 결과 하나로 확정. 확률 = `|확률진폭|²`
- 측정은 한 번에 하나만 주고, 실제 장치엔 오류가 있어 **QEC** 가 필요
- 1부 끝. 회로·게이트·중첩·측정을 봤으니, 2부에서 이 모든 것을 **벡터와 행렬** 로 다시
  정의한다.
</Callout>
